# 🔷 تطبيق دبب البترول — نظم المحلات بالآجل

**اللغة:** Kotlin  
**التخزين:** SQLite محلي فقط (`gas_db.sqlite`)  
**النموذج:** Repository Pattern + Data Layer منفصل عن UI  
**تاريخ الإنشاء:** 2026-08-29  
**المبدأ المطبق:** كل شيء محلي، لا سحابة، لا اتصال إنترنت مطلوب.

---

## 💡 سبب الفكرة (تحليل السياق)

أنت تعمل في **بيع أسطوانات غاز 20 لتر** (دبب بترول). المورد (المحطة) يعطيك بالآجل (تسحب من المحطة دون دفع فوري). أنت بدورك تبيع للزبائن، وقد يسدد بعضهم فوراً (`PAID`) وبعضهم لا يزال مديناً (`CREDIT` / بالأجل).

**المشكلة:** بدون نظام، تفقد العدد (كم عندي؟ كم بعت؟ لمن بعت؟ كم دين؟).

**الحل:** تطبيق محلي يتتبع:
- المخزون (كم أسطوانة متوفرة / كم مباع).
- عمليات البيع (من، متى، كم، بسعر، حيث السداد).
- الزبائن (اسم، تلفون، الدين الإجمالي، المدفوع).
- التقارير السريعة (إجمالي الدخل، إجمالي الدين، عدد الأسطوانات المتبقية).

## 🛡️ الإجراءات الدفاعية المُدمجة (المبدأ الرابع)

1. **الملف غير موجود:** يُنشأ تلقائياً عند أول تشغيل.
2. **بيع أكثر من المتاح:** `dispense()` يفحص كل أسطوانة قبل التعديل — إذا كانت غير متوفرة، يُرفض الصرف.
3. **سعر أو عدد سالب:** `Sale.init` يرفض عبر `require()`.
4. **زبون جديد:** إذا لم يُعثر عليه في البحث، يمكنك إنشاؤه عبر `addOrUpdate()` مباشرة.
5. **دفع جزئي:** `amountPaid` منفصل عن `totalAmount`. الدين المتبقي = `totalAmount - amountPaid` (تحسب بكل عملية، لا تُعدّل مباشرة).
6. **نسخ احتياطي:** يمكنك نسخ ملف `gas_db.sqlite` يدوياً كنسخة احتياطية.

## 🔧 كيف تستخدم (خطوات التطبيق)

### الخطوة ١ — إضافة أسطوانات جديدة (من المحطة)
```kotlin
val repo = CylinderRepoLocal(dbHelper)
repo.addCylinder(Cylinder(
    acquiredFromStation = "محطة أبو خالد",
    acquisitionCost = 12.5,
    sizeLiters = 20
))
```

### الخطوة ٢ — صرف أسطوانة لزبون
```kotlin
val cylinderRepo = CylinderRepoLocal(dbHelper)
val customerRepo = CustomerRepoLocal(dbHelper)
val saleRepo = SaleRepoLocal(dbHelper)

// ١. احفظ الزبون إذا لم يكن موجوداً
customerRepo.addOrUpdate(Customer(name = "محمد أحمد", phone = "01012345678"))

// ٢. صرف الأسطوانات (افترضنا 2 أسطوانة متوفرة)
val ids = listOf("CYL-...", "CYL-...")
val ok = cylinderRepo.dispense(ids)

// ٣. سجل البيع
val sale = Sale(
    customerId = customer.id,
    customerName = customer.name,
    cylinderIds = ids,
    unitsSold = ids.size,
    pricePerUnit = 25.0,
    totalAmount = 50.0,
    amountPaid = 25.0,   // دفع نصف فقط
    status = PaymentStatus.CREDIT,
    notes = "سدد نصف المبلغ فقط"
)
saleRepo.recordSale(sale)
```

### الخطوة ٣ — التقارير السريعة
```kotlin
val stats = """
المخزون المتاح: ${cylinderRepo.getAvailableCount()}
المباع: ${cylinderRepo.getSoldCount()}
إجمالي المدفوع: ${saleRepo.getTotalRevenue()}
إجمالي الدين (بالآجل): ${saleRepo.getTotalCredit()}
"""
```

### إصلاحات جوهرية أُنجزت
1. **البحث عن الزبون كان معطلاً** — لا نتائج ولا زر إنشاء؛ الآن يبحث فورياً مع اقتراحات + زر «＋ زبون جديد».
2. **أزرار GlowingButton لم تستجب للنقر** — أُضيف `clickable`.
3. **`kapt` ينهار مع Kotlin 2.0** — تمت الترقية إلى **KSP** (أسرع وأحدث).
4. كانت **ملفات Gradle الجذرية و`res/` كاملة مفقودة** — أُنشئت (settings/build/properties/wrapper + أيقونات + ثيم).
5. **دين الزبون في البيع النقدي** — كان يزداد خطأً؛ الآن يضاف للمدفوعات أيضاً.
6. قاعدة البيانات تُفتح عبر Singleton موحّد (`AppDatabase.getInstance`) بدل 3 نسخ متفرقة.
